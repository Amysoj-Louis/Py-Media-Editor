# Py-Media-Editor

A Python-based media manipulation utility designed for automated audio and video editing tasks.

## Features
- **Audio Processing**: Crop, merge, and adjust audio tracks with ease.
- **YouTube Integration**: Download and process audio directly from video URLs.
- **Batch Processing**: Handle multiple files in a single execution pipeline.

## Tech Stack
- Python
- Pydub / MoviePy
- yt-dlp
